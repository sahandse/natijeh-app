# نتیجه — لایواسکور فارسی

اپ اندروید Jetpack Compose برای نتایج زنده فوتبال به زبان فارسی و راست‌چین.

## قابلیت‌ها

- ورود مستقیم به داشبورد (بدون صفحه نام کاربری)
- تب‌های امروز / زنده / بیشتر؛ لیگ، اخبار و علاقه‌مندی داخل بیشتر
- کارت بازی پوسترمانند با امتیاز درشت؛ لمس طولانی برای محبوب کردن
- تنظیمات: تم سیاه / سفید / سیستم، اعلان گل، روشن ماندن صفحه، شروع روی تب زنده
- بازی‌های امروز تا دو روز قبل/بعد، گروه‌بندی‌شده بر اساس لیگ (لیگ‌های ایران بالاتر)
- تب زنده با به‌روزرسانی خودکار؛ اگر بازی زنده باشد اپ روی همین تب باز می‌شود
- فیلتر «فقط محبوب‌ها»، pull-to-refresh، و رفتن از کارت بازی به تیم یا لیگ
- جزئیات مسابقه: رویدادهای قابل لمس، آمار، ترکیب روی زمین، رویارویی واقعی دو تیم
- صفحه تیم: هدر ورزشگاهی با امتیاز/برد/تفاضل، تب بازی‌ها و ترکیب و آمار، مربی از آخرین بازی
- پروفایل بازیکن از ترکیب، گلزنان و رویدادهای بازی
- جدول لیگ، گلزنان برتر، و برنامه هفته
- اخبار فوتبال داخلی و خارجی با لینک اصلی ورزش ۳ و تاریخ شمسی
- اعلان گل/کارت قرمز/شروع بازی برای تیم‌ها و لیگ‌های محبوب
- ویجت صفحه اصلی برای امتیاز تیم محبوب

## منبع داده (بدون کلید)

داده‌های زنده از API عمومی وب ورزش ۳ خوانده می‌شود؛ اخبار از RSS ورزش ۳. هیچ کلید Gemini یا سرویس پولی لازم نیست.

## نسخه

نسخه فعلی: **1.9.0** (`versionCode` 13)

ویژگی‌های نسخه ۱.۸:

- تم حرفه‌ای سیاه‌وسفید و حالت AMOLED
- کارت‌های یکپارچه برای مسابقه، تیم، بازیکن و لیگ
- دسترسی مستقیم به بازی‌ها، زنده، لیگ‌ها و محبوب‌ها
- انتخاب تیم، بازیکن، لیگ و مسابقه محبوب
- اعلان قابل تنظیم برای شروع بازی، گل، کارت قرمز، بازیکن محبوب و نتیجه نهایی
- لوگوی برداری و Adaptive Icon جدید
- انتخاب اولیه تیم‌ها و لیگ‌های محبوب
- حالت کارت فشرده یا بزرگ و Skeleton Loading
- سه حالت آماده اعلان: فقط گل، مهم و همه
- بازطراحی کامل تب زنده با داشبورد آماری و کارت‌های گرافیکی
- نمایش مسیرهای پخش رسمی آپارات، فوتبال ۳۶۰، ورزش ۳ و شبکه سه در WebView امن داخل برنامه
- رفع کرش کارت مسابقه زنده هنگام باز شدن داشبورد
- جست‌وجوی تیم، لیگ و بازیکن در انتخاب اولیه علاقه‌مندی‌ها
- بررسی بروزرسانی از مرجع رسمی GitHub Releases
- دریافت یک‌باره داده‌ها و تصاویر عمومی برای استفاده آفلاین
- نمایش منابع رسمی خلاصه بازی برای مسابقات پایان‌یافته داخل برنامه

شناسه نصب: `ir.natijeh.app` — این نسخه جدا از APK قبلی (`com.aistudio.natijeh.vdfgkx`) نصب می‌شود.

2. روی امولاتور یا گوشی اجرا کنید

## GitHub Actions

انتشار فقط با push کردن تگ هم‌نسخه با `versionName` (برای نمونه `v1.9.0`) انجام می‌شود. Workflow فایل‌های امضاشده APK و AAB را می‌سازد و به GitHub Release پیوست می‌کند.

کلید امضا در مخزن نگهداری نمی‌شود. پیش از انتشار این Repository Secrets را با یک کلید خصوصی جدید تنظیم کنید: `ANDROID_KEYSTORE_BASE64`، `ANDROID_STORE_PASSWORD`، `ANDROID_KEY_ALIAS` و `ANDROID_KEY_PASSWORD`.
